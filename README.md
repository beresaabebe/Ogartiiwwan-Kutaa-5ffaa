**Og-artiiwwan Kutaa 5ffaa** is a modern, high-performance Android application designed as a Grade 5 Arts textbook. It provides students with a seamless digital learning experience through advanced PDF rendering and intuitive navigation.

## 🚀 Key Features

- **Professional PDF Renderer**: High-quality native rendering with smooth vertical scrolling.
- **Seamless Navigation**: ViewPager2 integration for effortless horizontal chapter switching.
- **Monetization Strategy**: Optimized AdMob integration with mediation support for Facebook (Meta) and Unity Ads.
- **Engagement Tools**: In-App Reviews and Update APIs to ensure user retention and satisfaction.
- **Robust Performance**: Fully supports 16KB page sizes for modern Android devices.
- **Stability**: Firebase Crashlytics and Analytics for real-time monitoring and bug tracking.

## 🛠 Tech Stack

- **Language**: Java
- **UI Framework**: Android SDK (XML, Material Design 3)
- **Architecture**: Standard Android Activity/Fragment Lifecycle
- **Libraries**:
  - ViewPager2
  - Google Play Services Ads (AdMob)
  - Meta (Facebook) Audience Network SDK
  - Unity Ads SDK
  - Firebase (Crashlytics & Analytics)
  - Google Play Core (In-App Updates & Reviews)
- **Minimum SDK**: 24 (Android 7.0)
- **Target SDK**: 37 (Android 15)

## 🏗 Architecture

The project follows a standard Android architectural pattern using Activities and Fragments to manage the UI and lifecycle. It leverages `ViewPager2` for navigation and a custom PDF rendering engine for content delivery.

## ⚙️ Setup & Installation

To get a local copy up and running, follow these simple steps:

1. **Clone the repo**:
   ```bash
   git clone https://github.com/BeckyTech/Ogartiiwwan-Kutaa-5ffaa.git
   ```
2. **Open in Android Studio**:
   - File > Open > Select the project directory.
3. **Configuration**:
   - Ensure you have a `google-services.json` file in the `app/` directory (required for Firebase).
   - Sync the project with Gradle files.
4. **Build and Run**:
   - Press `Shift + F10` or the **Run** button in Android Studio.
